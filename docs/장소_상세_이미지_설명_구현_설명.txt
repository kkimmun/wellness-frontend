장소 상세 이미지 슬라이드 및 설명 표시 구현

1. 구현 목적
- DB의 PLACE_IMG에 여러 이미지가 등록된 장소는 등록 순서대로 모든 이미지를 상세 패널에 표시한다.
- 이미지가 2장 이상이면 가운데 이미지와 양옆 이미지를 이용해 기존 슬라이드를 넘길 수 있게 한다.
- PLACE.PLACE_DESCRIPTION 값을 기본정보 영역에 표시한다.
- 설명이 NULL, 빈 문자열 또는 공백뿐이면 "등록된 내용이 없습니다."를 표시한다.

2. 백엔드 변경
- GET /api/places/{placeNo}/detail API를 추가했다.
- 장소 기본정보는 PLACE, TYPE_DETAIL, TYPE을 조인하여 조회한다.
- 장소 이미지는 PLACE_IMG에서 DEL_YN='N'인 데이터 전체를 IMG_ORDER, IMG_NO 순서로 조회한다.
- 응답의 placeImages 배열 각 항목은 imgOrder와 imageUrl을 가진다.
- 회원과 비회원 모두 상세 화면을 볼 수 있도록 해당 GET 요청만 Security 허용 목록에 추가했다.

3. 프론트엔드 변경 파일
- src/api/place.js
  기존 /place/{placeNo} 요청을 실제 백엔드 명세인 /places/{placeNo}/detail로 변경했다.

- src/features/map/components/DetailPanel.jsx
  MapPage가 조회해 전달한 placeImages 배열을 ImageSlider에 연결한다.
  패널 내부의 중복 상세 API 요청을 제거해 장소를 한 번 선택할 때 같은 요청이 반복되지 않게 했다.

- src/features/map/components/ImageSlider.jsx
  상세 API가 반환하는 이미지 전체를 기존 중앙/이전/다음 슬라이드 구조로 표시한다는 주석을 추가했다.

- src/features/map/components/BasicInfoTab.jsx
  장소 설명 행을 추가하고 설명이 없을 때 빈 상태 문구를 표시한다.

- src/features/map/components/DetailPanel.styles.js
  긴 설명과 줄바꿈이 상세 패널 너비 안에서 정상 표시되도록 스타일을 추가했다.

4. 사용 방법
- 지도 핀을 선택하고 상세보기를 누르면 GET /api/places/{placeNo}/detail을 요청한다.
- 이미지가 한 장이면 현재처럼 한 장만 가운데 표시한다.
- 이미지가 두 장 이상이면 양옆에 보이는 이미지를 클릭해 순서대로 이동한다.
- 기본정보 탭의 설명 항목에서 DB 설명 또는 빈 상태 문구를 확인한다.
